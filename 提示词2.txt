七、Entfall 与删除线的判定

必须区分以下情况：

1. 印刷描述本身包含 Entfall 或 Wegfall
例如：
“Tachometer, Entfall Tachograf”
这可能是配置描述，不是人工删除标记。

2. 人工写出的 Entfall / entfällt / streichen / nicht erforderlich
这是删除要求的候选证据，必须确认其关联对象。

3. 清楚划过整条代码及描述的删除线
可记录为“人工删除标记清楚”，但仍不自动代表正式批准。

4. 仅划过部分描述
只能记录被划掉的具体部分，不得自动删除整个代码。

5. 红线位于行下方、旁边或跨越多行
不得仅凭颜色认定删除。必须检查是下划线、分隔线、箭头还是删除线。

6. 同一项目同时有删除和新增标记
分别记录原项、删除证据、新项和关联关系。
无法确定修改顺序时，标为冲突待确认。

删除标记明确且关联可靠时：
- 原始正文集合仍保留该项目。
- 修改后参考集合中将其标为“删除要求”。
- 若订单没有该项目，不能直接写“订单遗漏”。
- 应写“订单未记载，与该删除标记方向一致；修改批准状态仍需确认”。
- 若订单仍保留该项目，应写“订单仍记载被标注删除的项目，需核实删除要求是否应落实”。

标记含义或关联不清楚时：
- 不得从有效集合中静默移除。
- 标为 NEEDS_MANUAL_REVIEW。
- 明确说明不确定性对统计和结论的影响。

3. 页边或页底的 Notiz 可能属于整车要求，不一定属于最近一行。
4. 一个 Notiz 可以关联多个项目，但必须解释依据。
5. 无法可靠关联时，保留为独立要求。

“fehlt”表示检查时提出的缺项，不代表当前订单仍缺失。
必须重新查找订单正文及其他明确记载。

数量必须区分：

- 两辆车合计数量。
- 额外增加数量。
- 最终总数量。
- 数量口径不明。

“2. Warndreieck”不能未经确认直接解释为订单总数量 2。
订单存在相关代码，也不代表新增数量要求已经落实。

import pdfplumber
import pandas as pd
from pathlib import Path
import re

# =====================================
# 输入文件
# =====================================

INPUT_FILE = "FG Prüfung Am Ettersberg.pdf"

pdf_path = Path(INPUT_FILE)

OUTPUT_FILE = pdf_path.with_name(
    pdf_path.stem + "_DaimLER_FGPruefung.xlsx"
)

# =====================================
# Daimler Code格式
# =====================================

CODE_RE = re.compile(
    r'^[A-Z][A-Z0-9]{2,4}$'
)

HEADER_WORDS = [
    "Vor Übergabe an Kunden",
    "Seite",
    "Albert Ziegler GmbH",
    "Bestellung von"
]

END_WORDS = [
    "Gesamtpreis Fahrzeug netto",
    "Kaufpreis"
]


def clean(txt):

    txt = txt.replace("\xa0", " ")
    txt = re.sub(r"\s+", " ", txt)

    return txt.strip()


rows = []

with pdfplumber.open(INPUT_FILE) as pdf:

    # 配置页
    for page in pdf.pages[1:20]:

        text = page.extract_text()

        if not text:
            continue

        lines = text.split("\n")

        for line in lines:

            line = clean(line)

            if not line:
                continue

            if any(h in line for h in HEADER_WORDS):
                continue

            if any(e in line for e in END_WORDS):
                break

            # 去掉章节标题
            if line.startswith("**"):
                continue

            # 识别：
            # F1X S-Fahrerhaus ClassicSpace
            m = re.match(
                r'^([A-Z][A-Z0-9]{2,4})\s+(.+)$',
                line
            )

            if not m:
                continue

            code = m.group(1)
            desc = m.group(2)

            if CODE_RE.match(code):

                rows.append([
                    code,
                    desc
                ])


df = pd.DataFrame(
    rows,
    columns=[
        "Code",
        "Description"
    ]
)


# =====================================
# 输出
# =====================================

df.to_excel(
    OUTPUT_FILE,
    index=False
)

print(df.head())
print()
print("共识别:", len(df))
print("Excel已生成:", OUTPUT_FILE)

def clean_value(value):
    """清理单元格内容"""
    if pd.isna(value):
        return ""

    value = str(value).replace("\xa0", " ")
    value = re.sub(r"\s+", " ", value)

    return value.strip()


def find_latest_xlsx_by_keywords(keywords):
    """
    自动查找当前文件夹中名称包含关键词的 xlsx 文件。
    如果有多个，选择最后修改时间最新的一个。
    """
    candidates = []

    for p in Path(".").glob("*.xlsx"):

        if p.name.startswith("~$"):
            continue

        name_lower = p.name.lower()

        for kw in keywords:
            if kw.lower() in name_lower:
                candidates.append(p)
                break

    if not candidates:
        raise FileNotFoundError(
            f"未找到名称包含以下关键词的xlsx文件: {keywords}"
        )

    # 选择最新修改的文件
    candidates = sorted(
        candidates,
        key=lambda x: x.stat().st_mtime,
        reverse=True
    )

    print("找到候选文件:")
    for p in candidates:
        print(" -", p.name)

    print("使用文件:", candidates[0].name)
    print()

    return candidates[0]


def find_column(df, possible_names):
    """
    自动识别列名
    """
    for name in possible_names:
        if name in df.columns:
            return name

    raise ValueError(
        f"未找到列名。候选列名: {possible_names}，实际列名: {list(df.columns)}"
    )


def build_code_dict(df, code_col, desc_col):
    """
    建立 Code -> Description 字典
    保留第一次出现的 Code 顺序
    """
    result = {}

    for _, row in df.iterrows():

        code = clean_value(row.get(code_col, ""))

        if not code:
            continue

        desc = clean_value(row.get(desc_col, ""))

        if code not in result:
            result[code] = desc

    return result


# ==================================================
# 主程序
# ==================================================

def main():

    # ==================================================
    # 自动识别两个 Excel 文件
    # ==================================================

    bestell_file = find_latest_xlsx_by_keywords(
        BESTELL_KEYWORDS
    )

    fg_file = find_latest_xlsx_by_keywords(
        FG_KEYWORDS
    )

    print("Bestellunterlagen Excel:", bestell_file.name)
    print("FG Prüfung Excel:", fg_file.name)
    print()

    # ==================================================
    # 读取 Excel
    # ==================================================

    df_bestell = pd.read_excel(
        bestell_file,
        dtype=str,
        engine="openpyxl"
    )

    df_fg = pd.read_excel(
        fg_file,
        dtype=str,
        engine="openpyxl"
    )

    # ==================================================
    # 自动识别列名
    # ==================================================

    bestell_code_col = find_column(
        df_bestell,
        ["Code", "VCode"]
    )

    bestell_desc_col = find_column(
        df_bestell,
        ["Description", "Beschreibung", "Name"]
    )

    fg_code_col = find_column(
        df_fg,
        ["Code", "VCode"]
    )

    fg_desc_col = find_column(
        df_fg,
        ["Description", "Beschreibung", "Name"]
    )

    print("Bestell Code列:", bestell_code_col)
    print("Bestell Description列:", bestell_desc_col)
    print("FG Code列:", fg_code_col)
    print("FG Description列:", fg_desc_col)
    print()

    # ==================================================
    # 建立字典
    # ==================================================

    bestell_dict = build_code_dict(
        df_bestell,
        bestell_code_col,
        bestell_desc_col
    )

    fg_dict = build_code_dict(
        df_fg,
        fg_code_col,
        fg_desc_col
    )

    bestell_codes = set(bestell_dict.keys())
    fg_codes = set(fg_dict.keys())

    # ==================================================
    # 比较差异
    # ==================================================

    only_in_bestell = bestell_codes - fg_codes
    only_in_fg = fg_codes - bestell_codes
    matched = bestell_codes & fg_codes

    # ==================================================
    # 输出表：Only in Bestellunterlagen
    # ==================================================

    only_bestell_rows = []

    for code in bestell_dict.keys():

        if code in only_in_bestell:

            only_bestell_rows.append({
                "Code": code,
                "Description": bestell_dict.get(code, "")
            })

    df_only_bestell = pd.DataFrame(
        only_bestell_rows,
        columns=[
            "Code",
            "Description"
        ]
    )

    # ==================================================
    # 输出表：Only in FG Prüfung
    # ==================================================

    only_fg_rows = []

    for code in fg_dict.keys():

        if code in only_in_fg:

            only_fg_rows.append({
                "Code": code,
                "Description": fg_dict.get(code, "")
            })

    df_only_fg = pd.DataFrame(
        only_fg_rows,
        columns=[
            "Code",
            "Description"
        ]
    )

    # ==================================================
    # 输出表：Matched
    # ==================================================

    matched_rows = []

    for code in bestell_dict.keys():

        if code in matched:

            matched_rows.append({
                "Code": code,
                "Bestellunterlagen_Description": bestell_dict.get(code, ""),
                "FGPruefung_Description": fg_dict.get(code, "")
            })

    df_matched = pd.DataFrame(
        matched_rows,
        columns=[
            "Code",
            "Bestellunterlagen_Description",
            "FGPruefung_Description"
        ]
    )

    # ==================================================
    # 详细对比表
    # ==================================================

    detail_rows = []

    all_codes_ordered = []

    for code in fg_dict.keys():
        if code not in all_codes_ordered:
            all_codes_ordered.append(code)

    for code in bestell_dict.keys():
        if code not in all_codes_ordered:
            all_codes_ordered.append(code)

    for code in all_codes_ordered:

        in_fg = code in fg_codes
        in_bestell = code in bestell_codes

        if in_fg and in_bestell:
            status = "MATCHED"
        elif in_fg and not in_bestell:
            status = "ONLY_IN_FG"
        elif in_bestell and not in_fg:
            status = "ONLY_IN_BESTELLUNTERLAGEN"
        else:
            status = "UNKNOWN"

        detail_rows.append({
            "Code": code,
            "FGPruefung_Description": fg_dict.get(code, ""),
            "Bestellunterlagen_Description": bestell_dict.get(code, ""),
            "In_FGPruefung": "Ja" if in_fg else "Nein",
            "In_Bestellunterlagen": "Ja" if in_bestell else "Nein",
            "Status": status
        })

    df_details = pd.DataFrame(
        detail_rows,
        columns=[
            "Code",
            "FGPruefung_Description",
            "Bestellunterlagen_Description",
            "In_FGPruefung",
            "In_Bestellunterlagen",
            "Status"
        ]
    )

    # ==================================================
    # Summary
    # ==================================================

    df_summary = pd.DataFrame([
        ["Bestellunterlagen文件", bestell_file.name],
        ["FG Prüfung文件", fg_file.name],
        ["Bestellunterlagen Code数量", len(bestell_codes)],
        ["FG Prüfung Code数量", len(fg_codes)],
        ["Matched数量", len(matched)],
        ["Only in Bestellunterlagen数量", len(only_in_bestell)],
        ["Only in FG Prüfung数量", len(only_in_fg)],
        ["生成时间", datetime.now().strftime("%Y-%m-%d %H:%M:%S")],
    ], columns=["项目", "值"])

    # ==================================================
    # 输出 Excel
    # ==================================================

    output_file = Path(
        f"Vergleich_{fg_file.stem}_vs_{bestell_file.stem}.xlsx"
    )

    with pd.ExcelWriter(
        output_file,
        engine="openpyxl"
    ) as writer:

        df_summary.to_excel(
            writer,
            sheet_name="Summary",
            index=False
        )

        df_only_fg.to_excel(
            writer,
            sheet_name="Only_in_FG",
            index=False
        )

        df_only_bestell.to_excel(
            writer,
            sheet_name="Only_in_Bestell",
            index=False
        )

        df_matched.to_excel(
            writer,
            sheet_name="Matched",
            index=False
        )

        df_details.to_excel(
            writer,
            sheet_name="Details",
            index=False
        )

    # ==================================================
    # 控制台输出
    # ==================================================

    print("比较完成")
    print("Excel已生成:", output_file)
    print()
    print("Bestellunterlagen Code数量:", len(bestell_codes))
    print("FG Prüfung Code数量:", len(fg_codes))
    print("Matched:", len(matched))
    print("Only in Bestellunterlagen:", len(only_in_bestell))
    print("Only in FG Prüfung:", len(only_in_fg))


if __name__ == "__main__":

    try:
        main()

    except Exception as e:
        print("程序出错:")
        print(e)
        sys.exit(1)
